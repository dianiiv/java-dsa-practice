
# Java DSA Practice

A personal learning repository for practicing Java fundamentals, data structures, algorithms, and coding interview problems.

## Topics

- Java fundamentals: variables, data types, and conditionals
- Loops and arrays
- Object-oriented programming
- Data structures and algorithms
- Coding interview practice

## Practice Programs

| Program | Description |
|---|---|
| `GuessGame` | Practice with variables and data types |
| `AgeChecker` | Practice with conditionals and comparison operators |
| `GradeChecker` | Assign a letter grade based on a score |
| `NumberGuessingGame` | Practice with loops, conditionals, and random numbers |
| `Arrays` | Practice iterating through arrays and calculating a sum |

## Goal

Build a strong foundation in Java and problem-solving through consistent practice, small programs, and progressively more challenging exercises.

This repository is a work in progress as I continue learning and improving.
